# Projekti tutvustus

Raamaturadar on lihtne ja kasutajasõbralik veebileht, mis on loodud lahendama tuttavat probleemi, kui tahaks midagi lugeda, aga ei tea, millist raamatut järgmiseks valida.
Kasutaja saab avastada raamatuid oma eelistuste (žanr, keel, ilmumisaasta)põhjal või saada juhusliku soovituse „Feeling lucky“ nupuga.
